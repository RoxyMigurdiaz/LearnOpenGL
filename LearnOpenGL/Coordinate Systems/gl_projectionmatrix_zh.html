概述

电脑显示器是一个二维平面。OpenGL 渲染的三维场景必须投影到电脑屏幕上，成为二维图像。GL_PROJECTION 矩阵 用于这种投影 变换。首先，它将所有顶点数据从眼坐标变换到裁剪坐标。然后，这些裁剪坐标再通过除以裁剪坐标的 w 分量，变换为归一化设备坐标（NDC）。

因此必须记住：裁剪（视锥剔除）和 NDC 变换都整合在 GL_PROJECTION 矩阵 之中。以下各节说明如何用 6 个参数构建投影矩阵：left、right、bottom、top、near 和 far 边界值。

注意：视锥剔除（裁剪）是在裁剪坐标中进行的，刚好发生在除以 wc 之前。裁剪坐标 xc、yc 和 zc 会与 wc 比较进行测试。如果任一裁剪坐标小于 -wc，或大于 wc，该顶点将被丢弃。

随后，OpenGL 会在发生裁剪的位置重建多边形的边。

透视投影

在透视投影中，截头金字塔视锥（眼坐标）中的三维点会被映射到一个立方体（NDC）；x 坐标的范围从 [l, r] 映射到 [-1, 1]，y 坐标从 [b, t] 映射到 [-1, 1]，z 坐标从 [-n, -f] 映射到 [-1, 1]。

注意：眼坐标定义在右手坐标系中，但 NDC 使用左手坐标系。也就是说，位于原点的相机在眼空间中沿 -Z 轴观察，而在 NDC 中则沿 +Z 轴观察。由于 glFrustum() 只接受正的 near 和 far 距离值，在构造 GL_PROJECTION 矩阵时需要对它们取负。

请试用 GUI 应用程序，通过调整参数来可视化观察视锥并构造投影矩阵。

带视场角（FOV）的透视矩阵

在给定 near、far 平面以及特定窗口尺寸时，很难恰当地确定透视投影所需的 4 个参数（left、right、top 和 bottom）。你可以从垂直/水平视场角以及宽高比（width/height）方便地推导出这 4 个参数。不过，这些转换仅适用于对称透视投影矩阵。

使用垂直 FOV

如果已知垂直视场角为 θ，以及屏幕宽度（w）和高度（h），则可用直角三角形计算 left、right、top 和 bottom 参数。首先，用半垂直 FOV 角的正切求半高（top），然后用屏幕宽高比（w / h）计算半宽（right）。 


// 用垂直 FOV 创建对称视锥
// 将 4 个参数 (fovy, aspect=w/h, near, far)
// 转换为 6 个参数 (l, r, b, t, n, f) 
Matrix4 makeFrustum(float fovY, float aspectRatio, float front, float back)
{
    const float DEG2RAD = acos(-1.0f) / 180;

    float tangent = tan(fovY/2 * DEG2RAD);    // 半 fovY 的正切
    float top = front * tangent;              // near 平面半高
    float right = top * aspectRatio;          // near 平面半宽

    // 参数: left, right, bottom, top, near(front), far(back)
    Matrix4 matrix;
    matrix[0]  =  front / right;
    matrix[5]  =  front / top;
    matrix[10] = -(back + front) / (back - front);
    matrix[11] = -1;
    matrix[14] = -(2 * back * front) / (back - front);
    matrix[15] =  0;
    return matrix;
}

使用水平 FOV

首先，用半水平 FOV 角的正切计算半宽（right）。然后，用屏幕宽高比（h / w）计算半高（top）。 


// 用水平 FOV 创建对称视锥
// 将 4 个参数 (fovx, aspect=w/h, near, far)
// 转换为 6 个参数 (l, r, b, t, n, f) 
Matrix4 makeFrustum(float fovX, float aspectRatio, float front, float back)
{
    const float DEG2RAD = acos(-1.0f) / 180;

    float tangent = tan(fovX/2 * DEG2RAD);    // 半 fovX 的正切
    float right = front * tangent;            // near 平面半宽
    float top = right / aspectRatio;          // near 平面半高

    // 参数: left, right, bottom, top, near(front), far(back)
    Matrix4 matrix;
    matrix[0]  =  front / right;
    matrix[5]  =  front / top;
    matrix[10] = -(back + front) / (back - front);
    matrix[11] = -1;
    matrix[14] = -(2 * back * front) / (back - front);
    matrix[15] =  0;
    return matrix;
}
